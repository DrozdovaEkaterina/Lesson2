# IT-Эверест — тетрадь экспедиции с Екатериной

Самостоятельный интерактивный урок для детей 6–11 лет по теме «Вводный курс. День 2. Восхождение на Эверест технологий».

**[Открыть интерактивный сайт →](https://it-everest-ekaterina.mellowfig2049.chatgpt.site)**

Сайт открыт всем по ссылке: вход в аккаунт не требуется. Можно отправить ссылку ученику и проходить урок самостоятельно.

## Что внутри

- 8 остановок с короткими текстовыми репликами Екатерины и её фото.
- Оригинальные векторные рисунки, выполненные тонкими цветными линиями в стиле ручки, на тетрадном листе.
- 9 упражнений из методички: LearningApps и «Собери клавиатуру» на Набираем.ру. Все кнопки открывают задания в новой вкладке.
- Интерактивные пояснения к устройствам и деталям компьютера.
- Практика печати, памятки для Windows и Mac, инструкция по скриншотам, практика копирования текста.
- Подсказки, дополнительная практика, перерыв и свободный возврат по карте.
- Сохранение прогресса в localStorage, три итоговых вопроса, рефлексия и скачиваемая карточка экспедиции.

Ориентир — 45 минут. Можно проходить по частям. Для заданий удобнее компьютер с клавиатурой; интерфейс также адаптирован к телефону.

## Запуск

Сайт статический: сборка, npm-пакеты и серверная часть не требуются.

```sh
python3 -m http.server 4173 --directory dist --bind 127.0.0.1
```

Откройте локальный адрес, который выведет сервер. Для публикации подойдёт любой статический хостинг; папка сайта — `dist/`. Относительные пути поддерживают размещение в подпапке, в том числе на GitHub Pages.

## Проверка

При установленном Node.js:

```sh
npm run check
```

Проверяются JavaScript, восстановление данных, завершение маршрута, защита от преждевременной выдачи карточки и набор ссылок на упражнения.

## Методические замечания

Исходная методичка адаптирована к самостоятельной работе. Обращения к группе и общий чат заменены индивидуальными подсказками, упражнениями и рефлексией. В таблице исходника время начала этапов противоречит длительностям; в сайте нет принудительного таймера.

Ссылка `learningapps.org/5171020` в исходнике указана как задание про внутренние детали компьютера, но фактически это «Пиктограммы файлов и программ». Она оставлена как бонус с корректным названием; объяснение процессора, оперативной памяти и накопителя находится внутри тетради.

Ссылка `nabiraem.ru/games/keyboard` ведёт на игру о расположении клавиш, поэтому описание исправлено; для практики набора добавлено отдельное поле внутри сайта.

Прохождение внешних упражнений подтверждает сам ребёнок. Сайт не получает оценки от LearningApps. Отметка об открытии ссылки не считается выполнением. Итоговая карточка доступна после отметки всех остановок и правильных ответов на три вопроса. Это памятная карточка, а не удостоверение проверки всех навыков.

В играх LearningApps могут использоваться обозначения клавиш Windows. Перед ними есть локальная памятка для Windows и Mac. Lightshot сохранён как дополнительный вариант; установка расширения не обязательна. Инструкции сверены с [Microsoft](https://support.microsoft.com/en-us/windows/apps/use-snipping-tool-to-capture-screenshots) и [Apple](https://support.apple.com/ru-ru/102646).

Данные хранятся только в браузере на этом устройстве. На странице нет аналитики, аккаунтов, форм отправки данных или загрузки детских файлов. Внешние тренажёры и Google Fonts используют собственные правила доступа и обработки запросов.
